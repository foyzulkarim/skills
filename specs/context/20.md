## Description

## Problem
The `start-task` skill uses LLM-mediated `gh` calls to fetch GitHub issues, which is slow and wasteful for a purely deterministic operation.

## Solution
Create a standalone bash script `scripts/gh-start-task.sh` that:
- Takes issue number + optional type + slug as args
- Fetches issue via `gh issue view --json`
- Auto-detects type from labels
- Derives slug from title
- Syncs git, creates/pushes branch
- Writes `specs/context/{issue-number}.md`
