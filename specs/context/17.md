# Task Context: Fix Review Sub-Skill Dispatch Mechanism

> **Date:** 2026-05-04
> **Branch:** fix/17/fix-review-subskill-dispatch
> **Sources:** GitHub issue #17, REQ at specs/requirements/REQ-fix-review-subskill-dispatch.md

## Task

- **Type:** fix
- **Title:** Fix review skill sub-skill dispatch mechanism
- **Issue:** https://github.com/foyzulkarim/skills/issues/17

## What

The review skill's Step 3 dispatch instructions are broken — sub-skills can't be invoked because the instructions reference filesystem paths that aren't resolvable skill names. The fix makes sub-skills reference documents that the orchestrator reads and applies via parallel Agent tool calls.

## Acceptance Criteria

| ID | Requirement |
|----|-------------|
| R1 | Dispatch section instructs parallel Agent tool calls with prompt template referencing sub-skill SKILL.md paths |
| R2 | All 16 sub-skill frontmatter blocks contain only `name` and `description` (no `trigger` field) |
| R3 | All 16 sub-skill `name` fields remain fully qualified (`review/{check-name}`) |
| R4 | "You Must NOT" section reworded to require reading sub-skill SKILL.md files instead of banning Agent calls |
| R5 | Main SKILL.md description reflects new dispatch mechanism |
| R6 | Available Checks table references file paths, not dispatch paths |
| R7 | Sub-skill body content (criteria, checklists, output formats) unchanged |

## Scope

**In scope:**
- `dev-pipeline/skills/review/SKILL.md` — dispatch instructions, description, "You Must NOT" section, Available Checks table
- All 16 sub-skill SKILL.md files under `dev-pipeline/skills/review/sub-skills/*/SKILL.md` — frontmatter only

**Out of scope:**
- Sub-skill review criteria, checklists, output formats
- Other skills in the plugin
- Plugin version bump
