# Task 22: Optimize file reads: replace glob+grep with native bash

- **Type:** feat
- **Source:** GitHub issue #22
- **State:** OPEN
- **Labels:** none
- **Created:** 2026-05-07

## Description

## Problem

Currently, file discovery and searching across the codebase uses a combination of `Glob` and `grep` via the Bash tool. This is slow and creates unnecessary overhead when native bash alternatives exist.

## Proposed Solution

Replace `Glob` + `grep` patterns with native bash constructs:

| Current | Proposed |
|---------|----------|
| `Glob` for file discovery | `find . -name "*.md"` |
| `grep -r "pattern"` via Bash | Bash `grep` or `grep --line-buffered` |

Native bash file operations are significantly faster for large codebases and avoid the overhead of spawning separate tool invocations.

## Scope

Audit all skill SKILL.md files for usage of `Glob` and `grep`, then replace with bash equivalents where applicable.

## Expected Outcome

Faster file operations, reduced tool overhead, and simplified tool chain.
